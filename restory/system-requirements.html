ReStory: Chill Electronics Repairs System Requirements — Can Your PC Run It?

Updated: August 2026 • 3 min read
Quick Answer:
  • Minimum: Win10 x64 / 2-core/4-thread CPU / 4GB RAM / GTX 750ti / 1GB storage
  • macOS: macOS 14+ / Apple M1 / 8GB RAM / 1GB storage
  • File size: Only 1 GB download — one of the lightest games of 2026
  • Linux/Steam Deck: Not officially supported in the playtest build

ReStory: Chill Electronics Repairs is a Unity-based shop management sim. Despite its detailed 3D device models, the game has surprisingly light system requirements — only 1 GB of storage and a GPU from 2014 or newer can handle it.

Good news: The minimum GPU (GTX 750ti) was released in 2014. Any gaming PC or even a budget laptop with a discrete GPU from the last 10 years should run ReStory smoothly. The 1 GB file size means you can download and start playing in under 30 seconds on typical broadband.

Important macOS note: ReStory requires an Apple Silicon processor (M1, M2, M3, or M4). It will not run on older Intel-based Macs. If you're on an Intel Mac, your only option is Boot Camp with Windows.

FAQ

Q: What's the download size?

A: 1 GB. Extremely small for a 3D game. Downloads in about 15-30 seconds on a 100 Mbps connection.

Q: Can I run it on integrated graphics?

A: Probably not well. The minimum spec calls for a discrete GPU (GTX 750ti). Newer integrated graphics (Intel Iris Xe, AMD Radeon 680M) might run it at low settings, but performance isn't guaranteed.

Q: Does it run on Steam Deck?

A: Not officially. The current playtest build is Windows-only. However, since it runs on Unity, Proton compatibility is likely. Check ProtonDB for community reports after the full release.

Q: Will there be a Linux version?

A: The developer hasn't announced Linux support. macOS (Apple Silicon) is the only non-Windows platform confirmed so far.
